Academic Submission Portals

Select the appropriate portal for undergraduate project work, student dissertation submission, or assessor documentation.

Undergraduate Project Work

For supervisors/examiners submitting project work records and scores.

  • Claim form and report
  • Excel score sheet validation
  • Completed project work
  • Scores consolidated for administration
Open Project Work Portal
2

Dissertation Submission

For students submitting their completed dissertation.

  • Student and programme details
  • Supervisor information
  • Dissertation topic
  • Dissertation file upload
Open Dissertation Portal
3

Assessor Submission

For assessors returning assessment documentation.

  • Assessment report
  • Claim form
  • Optional dissertation copy
  • Student identification details
Open Assessor Portal
